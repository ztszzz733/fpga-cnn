# 存储系统与 CPU/CNN 集成进度（2026-11-11）

## 当前结论

正式集成入口为 `rtl/soc/ees331/face_soc_ees331_mover_top.sv`，编译清单为 `rtl/filelists/system_ees331_mover23.f`。真实 CPU Control/Datapath、23 客户端真实 CNN、16 KiB CPU 本地 RAM、32 KiB tile RAM、DATA MOVER 和 HP0 在该顶层接通。PS GP0/HP0 与板外 DDR 在当前系统测试中由仿真模型提供。旧 `face_soc_ees331_top.sv` 与 128 KiB `cnn_cache` 路径仍保留作对照，不参与新顶层。

这是一版**通过所列 RTL 仿真、但尚未达到 FPGA 整机硬件验收条件**的集成工程。

## 已完成

1. 新存储路径：23 路 CNN 请求经轮转仲裁访问 32 KiB 全相联分页本地 RAM；缺页由 DATA MOVER 经 AXI3 HP0 搬入；脏页替换或范围栅栏写回 DDR。CPU 本地 RAM 保持固定一拍访问。
2. 保持现有 CPU 固件所需的缓存 CSR、只读区保护、故障状态和清写/失效语义。生产 CPU/CNN 算术 RTL 没有为通过本轮测试而修改。
3. 四组真实 CPU＋CNN＋新存储顶层仿真 PASS：短行、单帧 8×8×32、四帧 8×8×32、四帧六类算子。逐字节输出与旧缓存路径一致；四帧六类算子最终输出 SHA-256 为 `d961e0eb6f303e1f4e49a9792e92778ba2d4f5b4ee6600976d3417ee6f9d08f0`。
4. 额外执行三组 K1 选择测试，累计 23/23 个物理 CNN 客户端均实际启动，三次 44 任务样例输出完全一致。详细记录在 `simulation/build/mover23_soc/coverage23.json`；包内不附编译缓存，运行脚本可重建记录。
5. 定向故障测试 PASS：非对齐字访问、只读区写入、AXI 读错误、CSR 恢复、已接受请求取消后的 DDR 排空。
6. Vivado 2025.2 对 `xc7z020clg484-1` 完成 PL 侧综合；综合本身 PASS。资源估计：71,101 LUT / 53,200（超 17,901），137.5 / 140 BRAM36 等效 tile，61 / 220 DSP。**当前 23 路整机资源不能装入目标器件**。

## 测试来源和覆盖边界

短行和单帧 tile 来自 `simulation/incoming/cases/` 的确定性合成诊断数据；四帧 tile 由脚本复制到独立 DDR 工作区；六类算子来自 `deliverables/self_cnn_four_frames/data/` 的 11 步/帧诊断图。三组 K1 选择测试是存储侧新增的测试任务，只改变测试配置使能掩码。它们证实 23 个客户端都能实际工作，但不表示 23 路同时计算。当前四帧六类算子图不是完整 131 步 MobileFaceNet，也不是识别准确率测试。

## 尚未完成

1. 在保持 23 路配置的前提下收敛 XC7Z020 的 LUT/BRAM，并完成带约束的布局布线和时序验证。
2. 在新存储路径上运行完整 131 步网络及更长时间、高冲突、随机故障负载。
3. 与 PS 方确认 DDR 保留物理区、初始化、缓存一致性；接真实 PS7/板外 DDR 并上板验证。
4. 可下载 IMEM、CPU 停机加载口和 GP0 加载器尚未接入此生产顶层；本地 RAM 的加载端口目前关闭。

## 获取与复现

GitHub 发布分支：`bai-datasram`。下载同一分支的工程 ZIP 并解压，在工程根目录使用 `rtl/filelists/system_ees331_mover23.f`。先在 `simulation/` 运行 `python scripts/prepare_pool23_soc.py`，然后运行 `python scripts/run_mover23_coverage.py` 或 `python scripts/run_mover23_soc.py four_frame_all_ops`。故障测试入口为 `python scripts/test_mover23_faults.py`。脚本会在 `simulation/build/` 生成本机编译与结果记录；本包附 SHA-256 文件清单用于核对下载内容。

详细接口及数据见 `docs/storage_mover23_contract_20261111.md`、`docs/storage_mover23_integration_report_20261111.md`。此发布为工程源码和可重建测试输入，不包含 Vivado/Verilator 编译缓存、第三方 GTKWave 可执行包或真实板级验收结论。
