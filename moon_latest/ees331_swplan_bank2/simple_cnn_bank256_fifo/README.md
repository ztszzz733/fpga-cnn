# 256 位 bank 的结果 FIFO 扩容

实验版使用两块 96 KiB bank，算子读口最高 64 位，宽写为 256 位。分页器、bank 仲裁和 MOVER 与原 256 位实验版逐文件一致。

- 两路 3×3 各增加 1,024 项结果 FIFO。每项存 32 位地址和 32 位结果。算子把结果放进 FIFO 后可以继续算，后台写桥逐项写入 bank。最终完成信号等待所有写回收到应答。
- 两路 1×1 各增加一个 2,048 项结果槽，合计 10,240 项。两个 4,096 项大槽都占用时才启用小槽。使用新增槽时，按可存结果数决定当前分块大小。新增槽读取 256 位写数据需要两拍。

## 验证结果

| 指标 | 原 256 位版 | FIFO 版 |
| --- | ---: | ---: |
| BRAM36 | 76 | 84 |
| LUT | 26631 | 26989 |
| FF | 19033 | 19208 |
| DSP | 18 | 18 |
| WNS | 0.147 | 0.387 |
| WHS | 0.019 | 0.028 |

3×3 FIFO 分别用 [2.0, 2.0] 块 BRAM36，1×1 FIFO 分别用 [10.0, 10.0] 块 BRAM36 等效容量。
大用例周期从 2,492,274 降至 1,828,016。
3×3 FIFO 占用峰值为 128 / 128 项，满队列停顿为 0 / 0 拍。
内存压力用例中，两路 1×1 各使用小槽 14 / 14 次。

## 复现

用 WSL 运行 `bash run_fifo.sh`。功能回归覆盖对齐卷积、非对齐和边界、512 输出通道、分页驱逐压力、两路 1×1 小槽同时使用，以及 1×1、3×3 各自中止后重启。大用例的四个卷积和旧版输入、权重、存储布局相同。周期从任务提交算到算子完成。DDR 模型用于功能和周期比较，末尾参考校验所用显式刷回在这个计时窗口之外。

新建 Vivado 工程时，可设置 `EES331_CNN_VARIANT=bank256_fifo` 选择本版。布局布线范围为 CNN、分页器、双 bank 和 MOVER。整机接口做了 Verilator 展开检查。
