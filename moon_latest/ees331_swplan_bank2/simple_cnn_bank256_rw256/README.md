# 四算子 bank 256 位读写

以四通道 3×3 版为基线。在已有 256 位整笔写入的 bank 上，复用同一组八个 32 位 BRAM 条带。算子读请求起始地址满足 32 字节对齐且范围至少还有 32 字节时，每次读出一个完整 256 位字，通过分页器返回给对应算子。短头尾使用 64、32 或 8 位读。一个 bank 的计算口每拍接一笔。两路 3×3、两路 1×1 的输入与权重均能走新读路径。

读桥暂存整笔返回，再按现有卷积内部装填接口逐段交给缓存。3×3 的装填每拍接收单字节或 32 位，1×1 的对齐像素装填最高 64 位。DDR 侧仍由 MOVER 按页搬运。

## 同用例比较

| 用例 | 64 位读周期 | 256 位读周期 | 周期变化 | 按 100 MHz 换算 |
|---|---:|---:|---:|---:|
| 原布局，四算子并行 | 1,383,954 | 1,376,170 | -0.56% | 13.840 → 13.762 ms |
| 输入和权重 32 字节对齐，四算子并行 | 1,376,229 | 1,382,686 | +0.47% | 13.762 → 13.827 ms |
| 原布局，仅两路 1×1 | 1,026,737 | 1,026,689 | -0.00% | 10.267 → 10.267 ms |

原用例两路 3×3 均为 48×32×16 输入，32 输出通道。两路 1×1 同输入尺寸，96 输出通道。每一行对照共用任务和地址。整批周期覆盖模拟 DDR 补页、脏页驱逐、读、计算和写入 bank。显式刷新以验证 DDR 输出的周期在表外。

原布局的算子侧统计如下。请求指分页器接收的物理访问粒度。输入阶段包括等待读请求服务。两种位宽的实际总读取字节一致。

| 算子 | bank 读请求数 | 新版 256 位读请求数 | 输入阶段周期 |
|---|---:|---:|---:|
| 3×3 第一路 | 6,336 → 5,727 | 203 | 478,256 → 465,907 |
| 3×3 第二路 | 6,336 → 5,727 | 203 | 456,269 → 445,810 |
| 1×1 第一路 | 3,264 → 993 | 757 | 65,658 → 64,757 |
| 1×1 第二路 | 3,264 → 993 | 757 | 55,780 → 50,658 |

32 字节对齐布局的算子侧统计如下。

| 算子 | bank 读请求数 | 新版 256 位读请求数 | 输入阶段周期 |
|---|---:|---:|---:|
| 3×3 第一路 | 6,336 → 1,584 | 1,584 | 465,793 → 400,832 |
| 3×3 第二路 | 6,336 → 1,584 | 1,584 | 438,765 → 471,819 |
| 1×1 第一路 | 3,264 → 816 | 816 | 57,210 → 56,890 |
| 1×1 第二路 | 3,264 → 816 | 816 | 61,170 → 63,647 |

两种位宽各通过 17 组 Verilator 仿真。覆盖四路共享、输入跨 1 KiB 页、非对齐头尾、权重边界、DW3、步长 2、512 通道、256 位读中止并重新启动。大用例逐项核对 383,232 个 INT32 输出。整机 RTL 通过 Verilator 展开检查，LUT、FF 和板级时序待 Vivado 复测。
