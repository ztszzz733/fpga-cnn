# 1×1 权重缓存扩到 2 KiB

每路 1×1 把本地权重 RAM 加到 512 个 32 位字。整套权重满足缓存条件时，在第一块计算前搬入本地，后续像素块复用同一份权重。大于 2 KiB 的层继续按通道交替装填权重。输入分块、结果 FIFO、256 位写口和双 96 KiB bank 沿用 3×3 宽写版。

## 实测对照

| 测试 | 1 KiB | 2 KiB |
| --- | ---: | ---: |
| 四路整批拍数 | 1,824,359 | 1,867,678 |
| 只跑两路 1×1 的整批拍数 | 1,145,899 | 1,026,737 |
| 每路 1×1 权重请求 | 4,608 | 1 |
| 每路 1×1 权重读取字节 | 73,728 | 1,536 |
| 单路 1×1 LUT | 3785 | 3785 |
| 单路 1×1 FF | 2171 | 2175 |
| 单路 1×1 BRAM36 | 10.5 | 10.5 |
| 单路 1×1 DSP | 9 | 9 |

大用例中每路 1×1 的输入为 48×32×16，输出为 48×32×96。每路输入读入 24 KiB，权重原来按每块重读，扩大后保留整套 1.5 KiB。四路大用例和只跑两路 1×1 的对照使用同样层形状、输入和权重。另有非对齐地址的 2,048 字节权重和 2,052 字节权重，分别验证恰好装满、超过容量两个分支。

资源数据来自单路 1×1 的 Vivado 独立综合。整机接口通过 Verilator 展开检查，整机时序需独立布线。

## 复现

在 WSL 运行 `bash run_weight.sh 2048` 验证新版本，改用 `1024` 可运行对照。新建 Vivado 工程时将 `EES331_CNN_VARIANT` 设为 `bank256_k1_weight2k`。
