# 1×1 页内突发写

两路 1×1 都可以把同一 1 KiB 页内的连续结果合成一笔写命令。每拍向 bank 写 256 位，一笔最多 32 拍，最后一个写入提交后才返回一次完成应答。结果面板边界和页边界都会截断突发。对不齐 32 字节或不足一拍的头尾用 32 位写逐字收尾。每路增加 1 KiB 的 LUTRAM 暂存，用来集齐一笔并让已经发出的突发在算子中止时可以排空。旧的 DDR 缺页补页和脏页搬回流程继续处理这两种事件。

## 同用例对照

大用例每路 1×1 的输入是 48×32×16，输出 48×32×96。四路测试还同时执行两路 3×3。整批周期从提交任务算到最后一路完成，包含模拟 DDR 补页和脏页搬回。比对结果前另发一次缓存写回命令，那段周期单独留在测试中。

| 用例 | 旧版周期 | 页内突发周期 | 周期变化 | 按 100 MHz 换算 |
|---|---:|---:|---:|---:|
| 两路 3×3 和两路 1×1 | 1,867,678 | 1,916,582 | +2.62% | 18.677 → 19.166 ms |
| 仅两路 1×1 | 1,026,737 | 1,027,240 | +0.05% | 10.267 → 10.272 ms |

四路测试中，每路 1×1 的逻辑写命令和完成应答都从 **18,432 次降到 576 次**，物理写入仍是每路 18,432 个 256 位拍。四路竞争时两路 1×1 的最长连续 bank 写分别为 31 和 31 拍，旧版为 1 拍。两路 1×1 等输出槽的周期分别从 695,211、682,176 降至 569,436、537,129。四路用例的 DDR 补页为 1,648 → 1,648 次，任务执行期脏页搬回为 1,322 → 1,326 次。

等输出槽的时间减少，但 1×1 完成时间只减少约 1%。四路整批仍由 3×3 的最后一路决定。新旧 3×3 计算量和读写量一致，完成周期不同。分页器在 DDR 换入或搬回应答上花了 1,376,414 → 1,378,250 拍，按 100 MHz 换算约 13.76 → 13.78 ms。这个计数和算子运行可以重叠。

新版本通过 10 组 Verilator 用例。包括跨页、非对齐、满页、突发中止时并发缓存写回、算子重启和逐 INT32 比对。对照两组复现已安装 2 KiB 权重缓存版的整批周期。100 MHz 是按周期换算的条件值。整机完成 Verilator 接口检查，LUT 增量和板级时序待 Vivado 验证。
