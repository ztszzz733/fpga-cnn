# 两个同类卷积实例的自动分配约定

本阶段在 CNN 内新增隔离验证入口 `quant_dual_scheduler`，复用真实 NEureka 核、现有量化后处理和 bank 仲裁 SRAM。生产六模块顶层和 CPU 固件尚未接入本入口。测试结果见 [交付说明](../deliverables/mobilefacenet_dual/README.md)。

## 当前结构

```mermaid
flowchart LR
    T[预编程任务表与依赖位] --> S[就绪任务选择与空闲实例派发]
    S --> A[NEureka 0]
    S --> B[NEureka 1]
    A <--> M[4 bank DATASRAM\n两个 INT32 临时槽]
    B <--> M
    M <--> P[一套量化与激活后处理]
    P --> C[最后写响应完成\n更新依赖位并释放槽]
    C --> S
```

两套卷积实例可以同时运行不同条带；每个实例仍为既有的 4×4 PE 配置。只有两个临时槽，因此两个卷积同时占用时，后处理不能再占第三个槽。可以出现“两路卷积”或“一路卷积＋后处理”的重叠，不承诺三者同时工作。

## 怎么决定给谁做

1. 每个任务携带依赖位图、配置地址、参数地址、输出地址、元素数、通道数以及图片/层/条带标签，不携带指定卷积实例编号。
2. 上游条带的量化结果收到最后写响应后才设置完成位。一个任务的所有依赖满足、且存在空闲临时槽时，才分配槽；后层任务优先，同层按提交编号。
3. 每拍最多将一个新条带派给一个已启用且空闲的卷积实例。两个都空闲时轮换优先级，只有一个空闲时直接选择那个，不等待另一个。
4. 一个条带包含两个 32 输出通道组，固定由同一实例顺序完成。两组之间实例仍算占用，防止抢占或换槽；已经运行的条带不能迁移。
5. 两组卷积和写事务排空后，槽进入待后处理状态。单个后处理单元选择一个待处理槽；最后写响应到达才释放槽并公布任务完成。

这是有限任务图的非抢占派发，不是负载预测或整网编译器。依赖图和地址合法性由生成器负责；没有运行中追加任务、动态内存分配或自动检测依赖环。先保留最多 32 个任务、两个槽、两个实例，未宣称已支持任意 3～5 个实例。

## 使能与清除

`engine_enable[1:0]` 在批次 `start` 时锁存：01 仅实例0、10 仅实例1、11 两个；00 报错。运行中修改外部使能不影响当前批次。`engine_busy` 表示整个条带的实例占用，`core_busy` 是 NEureka 核心状态，两者不等同。

`clear` 同时取消两路卷积、后处理和待响应事务，清除已编程标志、任务完成位与槽状态；重启需重新写入任务表。清除不会恢复 SRAM 已写数据。测试中的清除后重启会复位并重新装载初始 SRAM，不代表断点续算。

## 存储接口

CNN 侧从 11 路扩展为 21 路客户端，直接使用既有 `datasram_banked.CLIENTS` 参数，不改仲裁算法：

| 客户端编号 | 所属功能 |
|---|---|
| 0～8 | NEureka 0 的 288 位存储传输，拆成九个 32 位请求 |
| 9 | NEureka 0 配置字读取 |
| 10～18 | NEureka 1 的九个 32 位请求 |
| 19 | NEureka 1 配置字读取 |
| 20 | 量化后处理读参数/卷积结果、写 UINT8 特征 |

每个客户端分别握手、返回归属固定；同 bank 的访问轮询仲裁，4 个 bank 仍最多每拍各接受一次访问。21 路接口不等于每拍能完成 21 次访存。CPU 与图像桥在本测试中空闲。

配置和小图数据沿用上一阶段：两张真实人脸的局部三层网络，真实权重、全部64输出通道，14个条带。配置表已经为两个临时槽各准备两个通道组的寄存器镜像，实例选取不改变数值或存储布局。

## 验证重点与边界

- 双实例：检查同时进入计算阶段、同时接受访存，两个实例都接到多个任务。
- 仅实例1：所有相同任务自动转交实例1，实例0不被使用；与双实例最终结果相同。
- 非对称停顿：只阻塞实例0请求、保持返回畅通，确认另一实例可继续。
- 清除复位重启：独立验证中断执行后重新初始化并完成全批次。测试平台预热不更新限速计数，因此不同时传入 `+stall=1` 与 `+restart`；默认运行脚本将二者分开。
- 所有测试逐条带检查 INT32 卷积结果、UINT8 后处理结果、依赖与标签、槽独占、通道组归属、任务不重不丢、不可写区不变。

输入仍为 SRAM 预加载。UART 分批输入、输入行循环缓冲、完整网络残差路径、7×7 硬件、精度校准、CPU 命令接入及更多实例还没有完成。硬件周期与电脑仿真耗时分别报告，不能凭实例数量预设两倍加速。
