# 需要时怎样调整测试

日常只用 [测试教程](test.md) 中的一条命令。本页用于换电脑、只查某类问题或增加测试量。

## 换电脑前先准备工具

需要 Python 3.10 或更新版本，以及可用的硬件模拟器。当前项目在这台 Windows 电脑上使用 Vivado 2026.1 内置模拟器验证；其他电脑需要先自行安装工具。

已经装好 Python 和 Vivado 后，在项目目录执行：

```powershell
cd D:\cpu_control
python -m pip install -r scripts/requirements.txt
python scripts/run_tests.py --check-tools
```

第一条 Python 命令安装测试和绘图所需的依赖，需要联网；第二条检查模拟器能否找到。看到工具路径只是准备完成，还要按教程实际运行并得到 PASS。

已有独立 Python 环境、模拟器装在其他目录，或需要 Linux 用法时，查本页末尾的原版说明。当前电脑无需重新安装或重复配置代理。

## 常用时只选一种

以下命令都在项目根目录运行。

| 你想做的事 | 命令 |
|---|---|
| 完整检查并出图 | `python scripts/run_tests.py --plot` |
| 只查看指令识别相关测试 | `python scripts/run_tests.py --test decode --plot` |
| 只测一条指定指令 | `python scripts/run_tests.py --test decode --instruction ADD --random-cases 0 --plot` |
| 只测多条指定指令 | `python scripts/run_tests.py --test decode --instruction ADD,LW,BEQ --random-cases 0 --plot` |
| 指定指令只看执行阶段 | `python scripts/run_tests.py --test instruction --stage execute --instruction ADD,LW --random-cases 0 --plot` |
| 指定指令查看全部五级 | `python scripts/run_tests.py --test instruction --stage all --instruction ADD,LW --random-cases 0 --plot` |
| 多跑一些随机指令 | `python scripts/run_tests.py --random-cases 5000 --plot` |

`--instruction` 后面写 [测试指令表](../../tb/vectors/decode_cases.csv) `name` 列中的名字。`--stage` 可选 `fetch`、`decode`、`execute`、`memory`、`writeback` 或 `all`。完整解释、结果文件位置和独立多指令/依赖程序的区别见 [硬件接口与完整指令说明](硬件接口与完整指令说明.md)。

第一次不必调整时钟、复位时间或超时。默认设置位于 [测试配置文件](../../tb/config/tb_config.svh)，命令行明确填写的选项会覆盖文件中的默认值。日常短命令使用文件默认值；如果以后改过该文件，测试量也会随之改变。

## 想增加一条测试

1. 明确要检查什么，例如“刚读完数据，下一条加法能否拿到它”。
2. 先根据需求写出正确答案，再编写输入。
3. 指令识别的样例放在 [测试指令表](../../tb/vectors/decode_cases.csv)；连续执行的样例放在 [主测试文件](../../tb/unit/tb_cpu_control.sv)。
4. 保存后重新运行完整测试。修改指令表时同步更新项目 `docs/decode_table.csv`。

不能让被测代码自己生成预期答案，否则可能把同一个错误复制到两边。具体字段和完整参数只在需要时查原版，不必背下来。

## 哪些设置不能当作普通参数改

端口宽度、信号编码和存储器等待方式是双方约定。尤其不能把内存延迟从一拍改成两拍，就认为现有控制会自动适应。有关原因见 [存储器时序说明](存储器时序说明.md)。
