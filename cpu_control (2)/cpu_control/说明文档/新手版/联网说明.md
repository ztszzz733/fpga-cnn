# 什么时候需要管网络设置

日常运行本地硬件测试不需要联网。这台电脑已配置好代理，使用联网工具时保持 Clash Verge 运行即可，不需要每次重新查端口。

## 现有设置在哪里

| 文件 | 用途 |
|---|---|
| [代理参数](../../network/proxy.psd1) | 保存本机已确认的代理地址 |
| [项目命令配置](../../.codex/config.toml) | 给项目中启动的命令设置相同代理变量 |
| [代理辅助脚本](../../network/proxy.ps1) | 按需检查通路或启动程序 |

当前记录的代理地址是 `http://127.0.0.1:7897`。这是本机代理，不是虚拟机或开发板地址。

## 什么时候才需要排查

安装依赖、拉取资料等实际联网操作失败，或者你明确要求排查时，再检查代理程序和错误日志。不要为一次正常的离线仿真重新改网络配置。

若改了代理端口，要同步修改参数文件和项目命令配置。不要在这些文件里保存密码、令牌或私钥。

## 为什么写好配置还可能出现“重新连接”

命令的代理环境只对该进程及之后启动的子进程生效，不会反向传给已经运行的应用。保存项目代理参数也不等于保证桌面客户端保持连接。

以前的通路检查只证明当时的一次 HTTPS 请求可达，不证明登录状态和长连接一直正常。需要手动启动或诊断命令时，再查原版说明；本次文档整理没有重新执行联网检查。
