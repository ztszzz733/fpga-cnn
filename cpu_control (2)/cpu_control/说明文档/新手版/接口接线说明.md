# 控制模块和数据通路怎样连接

## 2026-10-08 六模块实际实现更新

当前板级顶层为 `rtl/soc/face_soc_top.sv`：六个平级大模块 `cpu_core / cnn / datasram / IEM / image_bridge / clock_unit`。CNN 的原生 mem_* 直接接 datasram，**不经过 CPU**；B 口仲裁和读写完成时序已写进 datasram 内部，不再实例化旧 CPU 存储子系统、独立适配器或系统 B 仲裁器。CPU A 口保留固定一拍，Control C1 和原 Datapath 计算模块不变。

UART 图像桥和时钟复位模块本次已有实际 RTL。图像桥为 IMIO 分块读写 + CRC32；时钟直通、复位三拍同步释放。封装 7 根数字 I/O，busy 灯是图像桥忙，不是 CNN busy。CNN 自带 MMIO：QUEUE_BASE=+0x08、TASK_COUNT=+0x18、START=0x3D；图像桥 error 保留，CNN 存储错误锁存 cnn_mem_fault，恢复需系统复位。

当前接线以 [顶层三组线小白说明](../../SoC顶层连线与总体IO说明_小白版.md) 为准；另见 [六模块图](../../docs/SoC芯片封装与内部IO层级连接图.md)、[修改说明](../../docs/CNN实际代码整合修改说明_小白版.md)、[UART 协议](../../docs/uart_image_bridge_protocol.md)、[本次验证](../../docs/soc_six_module_verification_20261008.md)。编译清单 `rtl/filelists/system_cnn.f`；测试 `python scripts/run_cnn_integration.py`。

**下面保留原章节作为注明日期的历史记录。** 其中“CPU 存储子系统”“外置 sram_b_arbiter”“image_io_bridge / clock_reset_unit 待实现”、旧 IMG0 协议草案、旧 stub 和旧逐层 MMIO 不再是当前板级接线依据。CPU C1 基本规则仍适用；历史仿真不代表本次板级上板通过。

## 第一次先看三类信息

| 信息 | 从哪到哪 | 用途 |
|---|---|---|
| 当前指令、寄存器编号、比较结果 | 数据通路 → 控制模块 | 判断指令类型、数据依赖和跳转条件 |
| 运算方式、读写类型等控制 | 控制模块 → 数据通路 | 随对应指令保存，之后在正确阶段使用 |
| 继续、暂停、取消及结果选择 | 控制模块 → 数据通路 | 决定当前流水线怎样前进 |

当前接口一共有 48 个端口：26 个输入、22 个输出，时钟和复位包含在输入内。数据通路另有存储器和 CNN 接口，不算在这 48 个之内。

## 最容易接错的地方

一条指令依次经历取指、识别、执行、访存、写回。信号名末尾的 d/e/m/w 分别对应识别、执行、访存、写回阶段。

同一组控制、寄存器编号和有效标记必须属于同一条指令。例如识别阶段刚产生的“加法控制”，要先保存到下一阶段，不能直接改变正在执行的另一条指令。

有效标记可以理解为“这一格里有需要执行的指令”。空格、复位或被取消的指令不能写寄存器、写内存或触发跳转。

## 真正接线时按这四步

1. 双方编译同一份 [共享定义](../../rtl/common/cpu_control_pkg.sv)，不要各自维护不同数字的同义名称。
2. 参照 [连接示例](../../tb/integration/cpu_control_link_example.sv)，逐根写明端口名。
3. 核对每根信号的方向、宽度和所属阶段；精确表在本页末尾的原版中。
4. 使用 [真实模块接入清单](真实模块接入清单.md) 做运行验证，不能只看编译成功。

## 必须一致的行为

- 控制模块本身不保存跨阶段状态，状态由数据通路保存。
- 流水寄存器先处理复位，再处理取消，之后才考虑更新或保持。
- 同步低有效复位表示在时钟上升沿检查复位信号是否为 0；控制模块的组合安全输出会立即响应复位输入。
- 分支比较使用已经选好最新值的寄存器数据；Store 的地址和要写入的数据分别处理。
- 寄存器 0 永远为零；实际写寄存器和写内存都要检查对应指令仍有效。
- 跳转指令保留自己的返回地址写入；只取消它之后的错误路径指令。
- 当前不支持乘法等待，预留的乘法忙信号固定为 0。

## 目前还有哪些没定

双方原则接受了接口方案，但最终启动地址、系统统一复位、存储器准确时序和 CNN 起始访问地址还要共同确认。CNN 控制脉冲由数据通路产生，状态由 CNN 返回，不新增控制模块直连端口。

启动地址在测试模型中默认零，可用 `RESET_PC` 参数修改；这是测试模型的设置，不是新增控制端口。
