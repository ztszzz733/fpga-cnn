# 卷积预取与流水优化：验证结果

保持3×3两套、1×1四套。本轮完成1×1双权重缓存预取、八字写回队列，以及3×3/DW3连续乘加流水。对照是上一版“四位置1×1＋原始3×3”，不是最早串行版。

## 六图小回归

同一六张8×8 RGB ROI、前三层及相关后处理/补边，48任务、614400 MAC、107784检查字节；四场景最终6144字节输出全部与整数参考和基线一致。

| 场景 | 上一版周期 | 本轮周期 | 周期减少 | 同频吞吐比值 |
|---|---:|---:|---:|---:|
| 正常并行 | 381,151 | 263,887 | 30.77% | 1.444× |
| 逐帧串行 | 951,631 | 701,935 | 26.24% | 1.356× |
| 预加载 | 366,223 | 260,719 | 28.81% | 1.405× |
| CPU访存竞争/慢结果读取 | 501,316 | 421,489 | 15.92% | 1.189× |

正常并行在假设100MHz下为2.63887ms。最终这轮电脑执行四场景3.941秒，编译66.225秒；不含开发、前面试验和综合时间。电脑时间与硬件周期不同。

最早未优化的小回归为570511拍；本轮263887拍。这仅是同一小数据的历史对照，不能按比例推算原完整六图的8.98秒。

## 单层和真实重叠

1×1通过68组数值对照，K3通过50组普通/DW3数值对照；两套测试分别包含3次clear重启、描述符锁存、13种非法配置及2组同拍响应。覆盖步长、奇数通道/尾块、未对齐、512通道和长延迟。

1×1样例4×4、64输入/64输出通道：40,667→22,993拍，约1.769倍。读写请求仍为5,376次、读取17,408字节，收益来自重叠和减少控制空拍。观察到3330拍MAC与读响应同拍、460拍MAC与写响应同拍；不是用busy推测重叠。另一个压力样例确实经历队列满，仍完整写出且正确。

- 普通3×3：5×5×64输入、3输出通道：73,662→58,164拍；连续有效MAC最长576拍。
- DW3：5×5×64输入、64输出通道：36,404→32,372拍；连续有效MAC最长9拍。

3×3仍逐字节加载，仍在计算结束后写回；计算流水不能消除全部访存时间。单层测试数值由独立标量参考生成，参考中间结果没有代替RTL计算。

Vivado2025.2，XC7Z020-CLG484-1，OOC综合。WNS非负表示通过此阶段的时钟约束；没有整机布局布线或板级频率结论。DSP为0表示乘法映射到逻辑。K1每套多一个RAMB18，四套共增加两个36Kb BRAM Tile；八字队列也有逻辑资源成本。

## 启用及范围

`CONV_OVERLAP=1`启用本轮两项优化。六图runner使用`--conv-overlap`；不带它、只带`--pw4`可回到上一版。默认硬件生成参数保留0，本轮新配置由仿真runner显式选择。

本轮没有重跑完整MobileFaceNet，也没有做卷积与后处理融合。32MiB实验SRAM、合成ROI、诊断量化不代表512KiB适配或识别准确率；不包含CPU固件/UART、层内条带输入。未启动长仿真或定时检查。
