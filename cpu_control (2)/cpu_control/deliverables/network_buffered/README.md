# 六帧中间缓冲区复用：验证结果

**四项真实RTL回归PASS；独立生命周期协议测试PASS。**

6帧任务交替使用两张不同人脸的小区域输入，经前三层卷积/后处理，再做一次人为增加的残差Add压力测试。不是完整神经网络，不包括UART。新增8槽的占用、代号检查与消费者完成后释放；所有槽反复使用，每次释放立即覆写0xD7，后续计算仍全部匹配参考。

中间工作池39,424字节（38.5KiB，含每槽64字节保护区）；若这6帧的中间结果各自保留不复用，逻辑张量合计136,704字节。该对比不包括输入、权重、命令/生命周期表、最终输出持久存储，也不是完整网络的SRAM容量结论。

| 场景 | 周期 | 分配/释放 | 等待缓冲条件周期 | 电脑仿真耗时 |
|---|---:|---:|---:|---:|
| dual | 297,264 | 42/42 | 2 | 165.65秒（复用先前PASS） |

每项60命令，核对136,704字节，42次预约及42次释放；6帧最终输出均在回收前保存，四项最终哈希一致。本次编译0.00秒，新执行的仿真合计319.37秒，当前运行总计321.64秒。表中复用项列的是原始PASS耗时，本次不重复执行。协议测试另外编译8.32秒、仿真0.020秒。此前有编译列表遗漏、宽读取尾部越界和压力测试时间上限不足的失败运行，已保留，以上耗时不是整个调试过程总耗时。

## 当前边界与对接

静态地址规划＋硬件运行时预约，尚非任意地址动态分配器。两组工作区有帧进入依赖，避免多个帧各占一半资源导致死锁；尚非无限输入队列。生产DATASRAM未改。

最终结果由测试台在done通知时取走后立即允许回收；接生产CPU/UART时还需增加输出消费握手，消费者没读完就不能释放。完整网络生命周期、权重分批加载、条带输入还未接入。配置和端口详见[接口说明](../../docs/network_buffered_design.md)。

实际残差保留例：帧0的中间结果T5，主分支最后卷积T7在第73831周期完成，槽3直到Add任务T9完成的第91533周期才满足释放条件，多保留了17702周期。
