# 图片流式版波形信号说明

完整视图 64 根信号，每个名称只出现一次，按输出端模块分组。

| 信号 | 位宽 | 来源 → 去向 | 功能 |
|---|---:|---|---|
| cpu_state | 2 | 顶层监测逻辑 → 波形观察 | CPU CORE 的寄存观测状态：0 RESET、1 IDLE、2 WORK、3 FAULT。 |
| cnn_state | 2 | 顶层监测逻辑 → 波形观察 | CNN 的寄存观测状态：0 RESET、1 IDLE、2 WORK、3 FAULT。 |
| sram_state | 2 | 顶层监测逻辑 → 波形观察 | DATASRAM 的寄存观测状态：0 RESET、1 IDLE、2 WORK、3 FAULT。 |
| imem_state | 2 | 顶层监测逻辑 → 波形观察 | IMEM 的寄存观测状态：0 RESET、1 IDLE、2 WORK、3 FAULT。 |
| bridge_state | 2 | 顶层监测逻辑 → 波形观察 | IMAGE_BRIDGE 的寄存观测状态：0 RESET、1 IDLE、2 WORK、3 FAULT。 |
| clock_state | 2 | 顶层监测逻辑 → 波形观察 | CLOCK 的寄存观测状态：0 RESET、1 IDLE、2 WORK、3 FAULT。 |
| soc_module_state | 12 | 顶层监测逻辑 → 波形观察 | 每模块两位，低到高：CPU、CNN、DATASRAM、IMEM、IMAGE_BRIDGE、CLOCK。 |
| soc_active | 6 | 顶层监测逻辑 → 波形观察 | bit0～5 对应上述顺序，状态为 WORK 的位为 1。 |
| soc_fault | 6 | 顶层监测逻辑 → 波形观察 | bit0～5 对应上述顺序，状态为 FAULT 的位为 1。 |
| sys_clk | 1 | 外部 → CLOCK | 外部输入时钟；本次仿真周期 10 ns。 |
| rst_n_in | 1 | 外部 → CLOCK | 外部低有效复位。 |
| uart_rx | 1 | 外部 → IMAGE_BRIDGE | 外部设备向 SoC 发送串口回复。 |
| imem_addr | 32 | CPU CORE → IMEM | 取指字节地址，程序计数器对应的访问地址。 |
| imem_re | 1 | CPU CORE → IMEM | 取指读取使能。 |
| dmem_addr | 32 | CPU CORE → DATASRAM | CPU 数据访问字节地址。 |
| dmem_wdata | 32 | CPU CORE → DATASRAM | CPU 写入的数据。 |
| dmem_wstrb | 4 | CPU CORE → DATASRAM | 字节写掩码；bit i 控制数据位 [8i+7:8i]。 |
| dmem_re | 1 | CPU CORE → DATASRAM | CPU 数据读取使能，固定一拍响应。 |
| dmem_we | 1 | CPU CORE → DATASRAM | CPU 数据写入使能。 |
| cnn_mmio_addr | 32 | CPU CORE → CNN | CNN 寄存器字节地址，基址 0x40000000。 |
| cnn_mmio_wdata | 32 | CPU CORE → CNN | CONTROL bit0 启动，bit1 取消；OUTPUT_BASE 指定结果起址。 |
| cnn_mmio_re | 1 | CPU CORE → CNN | CNN 寄存器读使能。 |
| cnn_mmio_we | 1 | CPU CORE → CNN | CNN 寄存器写使能。 |
| load_req | 1 | CPU CORE → IMAGE_BRIDGE | CPU 请求加载一批资料；完成后 CPU 拉低确认。 |
| cnn_mmio_rdata | 32 | CNN → CPU CORE | STATUS busy/done/error，已完成帧数、消费像素数及固定尺寸。 |
| cnn_mmio_ready | 1 | CNN → CPU CORE | 地址选中且有 MMIO 请求时的组合就绪信号。 |
| cnn_valid | 11 | CNN → DATASRAM | 位 0/1 分别是水平/垂直梯度特征写回；其余通道未使用。 |
| cnn_write | 11 | CNN → DATASRAM | 对应通道为 1 写、为 0 读。 |
| cnn_byte | 11 | CNN → DATASRAM | 对应通道为 1 表示字节访问，0 表示对齐的 32 位字访问。 |
| cnn_addr | 352 | CNN → DATASRAM | 11×32 位字节地址；通道 i 使用 [32i+31:32i]。 |
| cnn_wdata | 352 | CNN → DATASRAM | 11×32 位写数据；字节写使用该通道最低 8 位。 |
| cnn_cancel | 1 | CNN → DATASRAM | CONTROL bit1 取消或 bridge_error 错误中止，不回滚已写入的结果。 |
| cnn_status_busy | 1 | CNN → 顶层 | 固定六帧处理正在进行；包括等待 UART 像素。 |
| cnn_status_done | 1 | CNN → 顶层 | 全部帧处理完成脉冲；STATUS done 同时保持为 1。 |
| cnn_status_error | 1 | CNN → 顶层 | 流错误、内存错误或像素边界错误，结果无效。 |
| pixel_ready | 1 | CNN → IMAGE_BRIDGE | CNN 可接收下一像素；写回未排空时反压。 |
| compute_fire | 1 | CNN → 顶层 | 上一上升沿完成一个位置的两路 3×3 卷积。 |
| frame_done | 1 | CNN → 顶层 | 一帧全部结果写回响应排空后的脉冲。 |
| frames_done | 32 | CNN → 顶层 | 完成帧数，最终为 6。 |
| pixels_consumed | 32 | CNN → 顶层 | 已消费的累计像素数，最终为 1647456。 |
| dmem_rdata | 32 | DATASRAM → CPU CORE | CPU 固定一拍读返回值；没有单独 ready/rvalid。 |
| cnn_ready | 11 | DATASRAM → CNN | 每个通道获得对应存储体服务的就绪位。 |
| cnn_response | 11 | DATASRAM → CNN | 逐通道完成响应，读和写都有响应。 |
| cnn_rdata | 352 | DATASRAM → CNN | 11×32 位读返回值；字节读取符号扩展。 |
| cnn_mem_fault | 1 | DATASRAM → 顶层 | CNN 非法地址/非对齐字访问故障锁存；送状态监测和 LED 组合逻辑。 |
| imem_rdata | 32 | IMEM → CPU CORE | 同步返回的 32 位指令；复位/非法地址返回 NOP。 |
| load_complete | 1 | IMAGE_BRIDGE → CPU CORE | 六张图的像素全部交给 CNN，或发生接收错误；计算收尾看 CNN done。 |
| load_error | 1 | IMAGE_BRIDGE → CPU CORE | 本批像素流失败，支持包格式、包 CRC、UART 帧和超时检测。 |
| uart_tx | 1 | IMAGE_BRIDGE → 外部 | SoC 向外部设备发送 IMIO 请求。 |
| bridge_ready | 1 | IMAGE_BRIDGE → 顶层 | 桥的就绪状态，用于顶层 led_ready。 |
| bridge_busy | 1 | IMAGE_BRIDGE → 顶层 | 桥正在执行加载事务。 |
| bridge_error | 1 | IMAGE_BRIDGE → 顶层 | 桥失败锁存状态，用于监测和 led_error。 |
| pixel_valid | 1 | IMAGE_BRIDGE → CNN | 已校验像素有效；与 ready 同拍为 1 才传递。 |
| pixel_data | 8 | IMAGE_BRIDGE → CNN | 无符号灰度像素 0～255，逐行排列。 |
| pixel_sof | 1 | IMAGE_BRIDGE → CNN | 帧首像素标记，随像素握手。 |
| pixel_eof | 1 | IMAGE_BRIDGE → CNN | 帧尾像素标记，随像素握手。 |
| pixel_frame | 32 | IMAGE_BRIDGE → CNN | 帧编号 0～5，随像素握手。 |
| rx_receiving | 1 | IMAGE_BRIDGE → 顶层 | UART 回复接收阶段，包括协议头、像素和 CRC。 |
| packets_checked | 32 | IMAGE_BRIDGE → 顶层 | 校验成功且发布给 CNN 的包数。 |
| clk | 1 | CLOCK → CPU CORE,CNN,DATASRAM,IMEM,IMAGE_BRIDGE | 内部工作时钟，当前为 sys_clk 直通。 |
| rst_n | 1 | CLOCK → CPU CORE,CNN,DATASRAM,IMEM,IMAGE_BRIDGE | 异步置复位、三拍同步释放后的内部低有效复位。 |
| led_ready | 1 | 顶层 → 外部 | bridge_ready && !cnn_mem_fault。 |
| led_busy | 1 | 顶层 → 外部 | bridge_busy OR cnn_status_busy。 |
| led_error | 1 | 顶层 → 外部 | bridge_error OR cnn_mem_fault OR cnn_status_error。 |
