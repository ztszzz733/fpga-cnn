# 1×1四位置并行：小回归已通过

2026-10-23。保持3×3两套、1×1四套；每套1×1改为四位置并行、同步读/乘法/累加流水、对齐32位加载。所有结果均来自真实RTL，本轮未运行完整MobileFaceNet。

## 六图对照

同一六图8×8 RGB ROI、首三层及相关处理、48任务，每场景107,784字节检查，最终6,144字节输出全部逐字节匹配。串行场景按原runner逐帧串行提交；正常并行为六帧交错。

|---|---:|---:|---:|---:|
| 正常并行 | 570,511 | 381,151 | 33.19% | 1.497× |
| 串行对照 | 1,793,455 | 951,631 | 46.94% | 1.885× |
| 预加载 | 601,903 | 366,223 | 39.16% | 1.644× |

最终小回归电脑执行 5.547 秒，编译 78.820 秒；不包括此前调试、单测及综合耗时。周期表与电脑运行耗时是两回事。

## 单层及协议

65组数值对照、3次clear重启、描述符锁存、13种非法配置、2组同拍响应通过；覆盖奇数通道、未对齐、尾块、stride=1/2、1～512输入通道和访存反压。

示例4×4、64输入/64输出通道、65,536 MAC：208,789 → 40,667拍，约5.13倍；请求18,432 → 5,376次，读入字节量均17,408。计算阶段观察到64拍连续有效累加。该样例收益不能当成完整网络收益。

优化版综合时序达标：是。Vivado 2025.2，XC7Z020-CLG484-1，单引擎OOC综合；没有整机布局布线或板级频率验证。DSP=0表示本次工具将乘法实现于逻辑资源，不是没有乘法。

四个K1的缓存合计10个BRAM Tile（20个RAMB18），只是K1部分。没有解决整机512KiB容量问题。

## 使用与边界

`self_fixed_network_top`设`PW4=1`启用优化版，`PW4=0`保留旧版对照（默认0）；六图runner用`--pw4`选择。该选项是编译参数。

加载和计算尚未在同一引擎内重叠，缓存输入跨输出通道复用、权重跨四个位置复用；四套K1可跨图同时工作。边界块会降低通路利用率。

小数据不等于完整六图全网PASS，也不能据此将以前8.98秒直接按比例换算。32MiB实验SRAM、合成测试图、诊断量化；不代表上板容量、识别准确率、CPU/UART或层内条带输入。
