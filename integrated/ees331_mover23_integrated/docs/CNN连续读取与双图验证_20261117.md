# CNN连续读取与双图验证（2026-11-17）

当前两套K3/DW3与六套PW8已显式开启连续读取，四bank分页存储已接入正式工程。
READ_AHEAD参数默认0用于兼容旧单在途互连；fixed_schedule_compact中的当前八套卷积设置1。
每个客户端最多四笔有序读取，返回无ready，需要提前保留接收槽位；clear必须同时取消客户端和互连在途事务。
跨bank与首次命中/缺页路径会先排空该客户端旧响应，避免无ID接口乱序。
DW3权重可连续读取，稀疏图像访问保留安全单笔模式。

真实CPU、CNN、392KiB bank和MOVER参与；PS/DDR为仿真模型，无UART、无同图条带流式输入。
输出仍为每图7×7×128，DW7关闭，不是原始128维MobileFaceNet输出，也未评估识别准确率。
