# MobileFaceNet 小链条整数约定 v0

这是用于 RTL 对照的实验约定，不是经过识别准确率验收的部署量化方案。四张人脸图片只用于调试；首个硬件小链条使用 person_1 的局部区域和实际预训练权重。后续可替换尺度和乘数，不修改算术模块。

## 数据及算术

- SRAM 特征采用 HWC，激活保存为无符号 8 位，实数约为 `scale × (q - zero)`。
- 权重每个输出通道使用对称 INT8，`qw=round(w/sw)`，范围 -127..127。离线权重舍入使用 numpy 的 ties-to-even；运行时重定量使用下述 ties-away，两者明确区分。
- NEureka 按上游 bit-plane 格式接收 `qw+128`，配置 weight_offset=-128；输入仍是无符号激活，不使用错误的“bit26 输入符号”解释。
- NEureka 输出有符号 INT32，保留累加值，不提前压成 INT8。激活零点补偿与 BN 折叠后的偏置放在后处理完成。
- 输出空间与通道地址均以字节计。32 位累加结果要求 4 字节对齐。当前通道以 32 个输出一组发射，PW 的 64 个输入通道仍完整参与，不是只取一半。

卷积后处理对每个通道计算：

```text
A = sum(qx * qw)                   # 真实 NEureka INT32 输出
B = round(bias / (sx * sw)) - zx * sum(qw)
M = round((sx * sw / sy) * 2^R)
qout = clamp(round_away((A + B) * M / 2^R) + zy, lo, hi)
```

本轮 R=24，乘加在后处理内部使用 96 位有符号中间值，最终再夹紧到 uint8，避免负数先转成无符号。离线生成器检查 B、M 可装入有符号 32 位；96 位实现旨在先验证正确性，未做面积/时序优化，不是目前最终芯片成本。

`round_away` 是四舍五入，恰好一半时远离零，例如 1.5→2、-1.5→-2。移位为 0 时不加半单位。模块接受移位 0..63，其他值报错。

ReLU6 输出尺度选为 6/255，zero=0，lo=0、hi=255；因此上限 255 表示真实值 6。**同一电路只有把尺度和夹紧上下限一起设置正确，才是 ReLU6。** 后两层普通 ReLU 暂按本张图片局部浮点结果选择输出尺度，没有暗称全数据集已校准。

浮点零填充必须编码为激活零点。首层 normalized 输入 zero=128，因此边缘填充字节是128，既不是0，也不是预处理后的 RGB 黑色。

## 残差加法

```text
T = (qa - za) * Ma + (qb - zb) * Mb
qout = clamp(round_away(T / 2^R) + zo, lo, hi)
```

其中 Ma、Mb 分别近似两个输入尺度与输出尺度之比，先相加再统一舍入。每个输入都读取为 uint8，然后显式减零点。该模式的 bias 字段不参与计算。测试使用独立的数值向量，不能把它说成前三层里已经出现了残差连接。

## 后处理参数表与接口

每通道 5 个32位字，通道顺序与 HWC 相同：

| 字 | 内容 |
|---|---|
| 0 | 有符号 bias B，仅 INT32 重定量使用 |
| 1 | 有符号乘数 Ma/M |
| 2 | 有符号乘数 Mb，仅残差使用 |
| 3 | `[31:24] zo, [23:16] zb, [15:8] za, [7:0] R` |
| 4 | `[15:8] hi, [7:0] lo`，其余位保留 |

`quant_post_engine` 在 start 时锁存地址、元素数、通道数和模式，先把参数读进内部缓存，再按 HWC 遍历元素。当前最多512通道；参数首址须4字节对齐，INT32输入须4字节对齐，count和channels不能为0，lo不能大于hi。参数读取完成后才能算数。

一次只允许一笔未完成的 SRAM 命令；`valid && ready` 表示请求接受，`response` 表示事务完成。done 必须等最后一次输出写响应。clear 中止任务，集成端必须同时取消存储事务（本轮接到 cnn_cancel），不能让旧响应被下一任务误收。源和目的缓冲区由调度方保证无危险重叠；本模块不是地址范围保护单元。

## NEureka 配置限制

当前集成中 DW3×3 + stride2 + prefetch 开启会卡在 MATRIXVEC；关闭 prefetch 的相同小例已逐字节通过。本轮软件任务生成器默认只对这个组合关闭预取；`--force-prefetch` 用于复现历史失败。真实权重小链条为初次集成统一关闭内部预取。

这属于已验证的配置绕行，不等于修好了核心内部预取逻辑。外层双缓冲与算子之间的并发是另一件事；本轮小链条先顺序执行以定位数值问题，后续再恢复层间/条带重叠。
