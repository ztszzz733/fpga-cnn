## 网络语义

按用户确认，去掉 DW7 时直接保留 7×7 特征，不增加池化或其他替代算子。测试任务包删除原步骤 127（DW7）及 128（其关联的 Post），剩余 129 个任务。原末尾 PW 和 Post 使用原有权重、量化参数，在 7×7 特征上执行；最终为 UINT8、HWC 排列的 7×7×128，共 6272 字节。

这是一份改变了网络输出形状和数值的网络变体。数值参考用于检查此变体的硬件实现，不代表与原 1×1×128 模型等价或验证了识别精度。旧的软件接收端若固定读取 128 字节，需要按结果描述符的长度读取新输出。

## BRAM 修改

- K1：8 份像素 RAM 改为每通道一条 64 位记录，同时提供 8 个像素；两份权重缓存合为一份带 bank 地址的 RAM。外部 32 位输入先暂存，再逐字节提交，允许多用少量本地周期。
- K3：四个输入分区按实际覆盖的 9／6／6／4 个位置分配容量。1152 字等短尾 RAM 拆成 1024 字主体与短尾，避免短尾占用整块 BRAM36。
- Post 和 Add：五份独立参数 RAM 合为 144 位宽的每通道参数 RAM，保持原有数值流水和同步读延迟。
- 共享 RAM：空出的资源实际加入 tile RAM；分页器支持非二次幂页数，替换指针显式在最后一页回到零。
- 共享 RAM 的物理分块为 256＋128＋8 KiB，两个端口均保留一拍同步读。单一非二次幂数组曾被 Vivado 取整为 512 KiB 并挤占其他缓存的 BRAM，导致 LUT 超量；显式分块用于避免这种资源分配结果。

## 资源统计

Vivado 2025.2，器件 `xc7z020clg484-1`，全 SoC、外置 PS 接口、综合后统计。BRAM 数值按 RAMB36 等效计算，两个 RAMB18 等于一块 RAMB36。布线和时序尚未验证。

保留 32 KiB 共享 RAM 的缩减版实际综合为 35326 LUT、25830 寄存器、47 BRAM36 等效、33 DSP。记录位于 `simulation/build/runs/20261112_200153_reduced_synth_32768/`。

这份预算中，除共享 RAM 的 8 块以外占用 39 块。对比此前 23 算子整机的 137.5 块，释放 90.5 块；本次使用其中 90 块增加 360 KiB，共享 RAM 变为 392 KiB。

最终分块版的整机实际综合为 **49053 LUT（92.20%）、34978 寄存器（32.87%）、137 BRAM36 等效（97.86%）、33 DSP（15.00%）**。其中共享 tile RAM 实际使用 98 个 RAMB36，CNN 使用 27 个 RAMB36＋12 个 RAMB18，CPU RAM／IMEM 使用 6 个 RAMB36；没有把扩容容量留在仿真参数中而不落入物理 BRAM。

与原集成包的 71101 LUT 相比，减少 22048 个（约 31.01%）。最终 BRAM 总量只比原 137.5 块少 0.5 块，因为释放的空间已转为共享缓存。扩容同时增加了页表和仲裁逻辑，所以最终 LUT 高于保留 32 KiB 时的 35326 个。最终报告目录 `simulation/build/runs/20261112_203002_reduced_synth_401408/`，原版报告为 `evidence/synth/utilization.rpt`。

波形导出使用 `simulation/scripts/export_reduced_states.py`，保留真实 FSM 的全部状态变化。算子映射为：0～1 是 K3，2～7 是 K1，8～9 是 Post，10 是 Add，11 是 Pad。`ACTIVE` 表示持有任务，`WORK` 表示该拍执行相应工作；状态名还可区分请求、等待、MAC 和写出。
