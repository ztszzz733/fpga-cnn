# K3输入窗口与权重复用优化

已保留现有算子数量、CPU配置、算子间存储交换、共享392KiB RAM和MOVER；本次生产RTL只改`rtl/cnn_self/self_conv_spatial4_engine.sv`。没有运行完整MobileFaceNet或整机综合。

## 两项改动

1. `INPUT_HALO_REUSE=1`：对3×3、步长1的横向相邻tile，保留重叠的两列输入，仅加载新进入的列。现有bank中的列位置交替使用，读计算时使用相同映射，不复制数组、不增加BRAM。每个新tile行重新完整加载；步长2、kernel1和没有横向邻块的情况按原路径处理。尚未实现纵向窗口复用。
2. `WEIGHT_LAYER_REUSE=1`：当普通卷积确有多个tile，且整层权重可放进现有权重RAM时，只加载一次、按输出通道偏移访问。当前MAX_CHANNELS=512、MAX_KERNEL=3，对应4608字节上限；超出容量自动继续使用原来的逐输出通道加载方式，不扩大RAM。单tile没有跨tile收益，保持原路径。DW3继续使用已有的完整权重复用。

两项均默认开启；分别置0可关闭。`READ_WORD_BUFFER=1`保留此前的32位字缓冲优化。开始新命令、复位、clear时清除权重有效状态；横向输入复用仅发生在同一命令、同一tile行中。输入和权重在命令期间须保持不变。clear仍要求存储同时取消在途请求，沿用原接口约束。

端口、状态编码、MAC数量、算术格式和输出布局未改。结果仍写回存储后交给下一算子；没有算子间直连或融合。单个K3内部仍是加载/计算/写回分阶段，并未实现双缓冲预取或写回与计算重叠。

## 同条件小数据结果

下面的“前”是已开启此前小字缓冲、尚未开启本次两项复用的版本，不是最早版本。读请求按对外valid&&ready统计，排除写请求；读字节按实际外部访问宽度统计。时延为确定性反压存储模型下的单元周期，不代表DDR或全网增速。

| 用例 | 外部读请求 | 外部读字节 | 执行周期 | 耗时减少 |
|---|---:|---:|---:|---:|
| 16: 5×5, Ci=3, Co=3, 普通3×3 | 133 → 59 | 511 → 224 | 1541 → 1006 | 34.72% |
| 163: 6×6, Ci=64, Co=8, 普通3×3 | 5632 → 1920 | 22528 → 7680 | 42981 → 27355 | 36.36% |
| 164: 6×6, Ci=64, Co=64, DW3 | 1168 → 912 | 4672 → 3648 | 12642 → 11568 | 8.50% |
| 165: 9×9, Ci=32, Co=32, DW3 | 1872 → 1152 | 7488 → 4608 | 21162 → 18138 | 14.29% |
| 169: 7×7, Ci=16, Co=32, 普通3×3 | 10852 → 1460 | 43408 → 5840 | 276907 → 87644 | 68.35% |
| 170: 7×7, Ci=16, Co=33, 普通3×3 | 11176 → 11000 | 44704 → 44000 | 285216 → 281690 | 1.24% |

216个数值用例及独立标量参考、越界/输出守卫、写次数、MAC计数、反压稳定、立即返回、非法配置、描述符锁存、clear重启、无复位同地址换输入/权重检查通过。129个变快、87个不变，0个变慢，0个读字节增加。关闭两项功能后，原有168个用例逐一复现上一版周期、请求数和读字节数。另对一个64通道案例分别关闭/仅开窗口/仅开权重/全开，隔离两项收益，见unit日志中的ABLATION。

独立计算了每个tile应该加载的输入字节和权重字节，并核对核心计数。新增用例包含权重容量恰好4608字节和超出容量自动回退、奇数尺寸和横向尾块。第一次试验发现少数单tile预加载略慢，最终版已加入单tile回退；中间记录保留，但不作为最终版结果。

`input_reads/weight_reads`仍是核心逻辑实际装载的字节计数，不等于经过字缓冲后的外部流量；对外物理统计见本表。`mac_fire`含义不变。

## 小型SoC与资源

最终版8任务SoC PASS：17964个中间结果字节全部匹配，输出SHA与上一版一致。旧版131761周期，新版121283周期，耗时减少7.95%。这是固定小夹具结果，不是完整网络或多图吞吐结论；CPU/CNN/分页RAM/MOVER为RTL，PS/DDR使用仿真模型。

使用Vivado 2025.2、XC7Z020-CLG484-1、10ns约束、kernel固定3，其他端口保留。对照复用上次已核对的同设置K3独立综合报告，本次只综合新版一个K3。两套合计是单模块差值乘二，不是整机实测，未布局布线。此前字缓冲的资源已包含在“上一版K3”，本表为本轮额外增量。
