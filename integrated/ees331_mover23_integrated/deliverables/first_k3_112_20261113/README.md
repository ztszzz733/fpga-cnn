# 112×112 RGB首层3×3卷积对比

新版只运行补边及首层卷积，第二个任务完成即停止。旧版未重跑，直接读取此前完整仿真的首层START/COMPLETE事件。

## 相同配置

- 原图112×112×3，补边1后输入114×114×3。
- 普通3×3卷积、步长2、64输出通道，输出56×56×64个INT32（802816字节）。
- 原有图片、权重、独立整数参考、CPU配置模板、CPU/分页RAM/MOVER及DDR仿真模型；源码对照中唯一变化的生产文件是K3引擎。
- 仍先配置相同完整模板以保持旧记录的前置条件，但不执行后续网络层。旧、新卷积启动均在995262周期。
- 比较范围严格为首层卷积START到COMPLETE，包含算子访存及写回到共享缓存的应答；不包含CPU配置、图片上传、前置补边、后处理及最终DDR结果fence。不是单纯MAC耗时，也不表示结果已全部刷回外部DDR。

## 结果

| 指标 | 旧记录 | 新版 |
|---|---:|---:|
| 卷积启动周期 | 995262 | 995262 |
| 卷积完成周期 | 8659278 | 4067648 |
| 卷积耗时周期 | 7664016 | 3072386 |
| 按100MHz换算 | 76.64016ms | 30.72386ms |

节省4591630周期，即100MHz条件下45.91630ms；耗时减少59.91%，速度为原来的2.494倍。100MHz是条件换算，未进行上板时钟或布局布线验证。

这是相对11月12日保存旧版的累计收益，包含此前READ_WORD_BUFFER与本次WEIGHT_LAYER_REUSE，不是仅本轮两项新功能的独立收益。该层stride=2，INPUT_HALO_REUSE的stride=1横向复用路径不生效。1728字节权重可放入现有4608字节权重RAM，主要改进之一是保留整层权重，避免跨空间tile反复读取。

## 正确性及电脑耗时

真实RTL只完成2任务（补边、卷积），核对841804字节中间输出，包含全部802816字节卷积结果；每笔写请求检查参考值、边界及重复写，输出覆盖与只读模型保护通过。实际卷积输出SHA256：`f03b2674db42e19c4e956cbecb5132af1bc97dc8b4906a55d232847b205075e2`。

本次复用已通过验证且源码哈希一致的RTL编译库，RTL重新编译耗时0；仅编译新的提前结束测试入口用13.086秒，仿真执行17.148秒，脚本合计31.611秒。没有重跑旧版，没有跑完整网络，没有运行新的综合。
