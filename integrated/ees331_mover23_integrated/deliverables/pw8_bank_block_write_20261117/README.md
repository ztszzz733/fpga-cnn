# PW8到bank的块写回对比（2026-11-17）

**排除DDR后，带步长块写回使代表层总周期减少7.71%，累计写事务占用周期减少53.91%。输入通道较少、输出占比高时收益更大，本轮最高45.06%。** 本次先验证PW8，尚未推广到K3、Post、Add等算子或SoC。

## 测了什么

- 两边使用当前16路PW8相同计算和输入路径，关闭上一项`INPUT_WORD_FILL`试验，确保只比较输出协议。
- 输入与权重先通过真实RAM的初始化口预装，随后启动算子；计时从start到最终写入和应答全部完成。预装和结果读回检查不计入时间，没有DDR/MOVER/CPU/UART。
- 两边都是相同392KiB四bank RTL，每个bank计算口32位。本测试只有一个活动算子，每拍最多实际写入一个32位字，没有加宽bank，没有增加单拍写字数。
- 原版每个结果一次请求、一次完成；新版每组最多8个结果一次命令、连续数据拍、最后一次完成。单结果尾组保留原单字路径。
- 两边前端逐字事务及块末尾完成使用同样的两拍响应管线，bank RAM仍为同步读写。

## 整层周期

尺寸列为输入宽高和输入→输出通道，均为普通1×1、stride=1。

| 单图单层 | 逐字写回 | 块写回 | 总耗时减少 |
|---|---:|---:|---:|
| 7×7，32→64通道 | 14,669 | 13,012 | 11.30% |
| 14×14，64→64通道 | 88,079 | 81,285 | 7.71% |
| 28×28，64→64通道 | 342,352 | 315,590 | 7.82% |
| 7×7，128→128通道 | 75,583 | 72,457 | 4.14% |
| 14×14，128→64通道 | 153,868 | 147,461 | 4.16% |
| 14×14，16→64通道 | 41,890 | 33,747 | 19.44% |
| 14×14，4→64通道 | 38,621 | 21,219 | 45.06% |

14×14、64→64通道按100MHz条件换算为0.88079→0.81285ms。28×28对应3.42352→3.15590ms；没有本轮综合/布局布线，不能据此保证板级100MHz。

## 代表层写回开销

| 指标 | 逐字写回 | 块写回 | 变化 |
|---|---:|---:|---:|
| 实际写入32位字 | 12,544 | 12,544 | 不变 |
| 输出字节 | 50,176 | 50,176 | 不变 |
| 写请求/完成次数 | 12,544 | 1,600 | -87.24% |
| 累计写事务占用周期 | 37,632 | 17,344 | -53.91% |
| 输出队列满导致OREQ等待周期 | 8,046 | 1,539 | -80.87% |
| 读取请求数 | 7,232 | 7,232 | 不变 |
| MAC工作拍 | 51,200 | 51,200 | 不变 |

“累计写事务占用周期”从写命令接受到对应应答消费累加，包括数据传送/背压；可以与MAC计算重叠，不是独立串行阶段，不能把其差值直接从整层时间中扣掉。

## 为什么是带步长块写

PW8按同一输出通道跨多个空间位置产生结果，HWC格式下相邻结果地址间隔为`Co×4`字节，不是连续地址。新接口携带base、stride和word_count，bank逐拍生成正确地址；一个空间组/输出通道结束才形成一个块，支持1～8个位置。现有8项结果队列被复用，未增加整层结果缓存。

| 接口 | 信号 |
|---|---|
| 块命令 | `block_valid/ready`、`block_base[31:0]`、`block_stride[31:0]`、`block_words[3:0]` |
| 数据拍 | `block_data_valid/ready`、`block_data[31:0]` |
| 最终完成 | `block_response`、`block_response_error` |

不是收到命令就假报写完成：最终应答在最后一次RAM写入之后，算子done还要等待块应答排空。原有输入/权重读请求也共享同一bank访问能力，未给新版另开数据写端口。

## 正确性与范围

16组尺寸/通道/步长/非对齐/尾组/背压组合均通过，另通过块传送中clear取消后重启、描述符锁存。两边读取请求数、MAC工作拍和实际写字数一致；每次实际写入检查地址、数据和重复写，done后从真实RAM读回全部输出及前后保护字节。

16组没有总周期退步；单位置输出等无法形成块的场景可能没有收益。没有用外部假数组代替bank计算结果，也没有将应答提前到数据尚未写入时。

本次没有验证多算子同时竞争、DDR集成、完整网络或资源/时序；不能将该百分比直接套用整机。`self_pw8_block_engine.sv`和`block_bank.sv`是隔离试验模块，生产PW8、存储及文件清单均未修改。
