# 撤销卷积DSP映射

按用户要求，恢复DSP映射前的两个卷积生产文件，包括撤销use_dsp属性及DSP实验中加入的PW8像素RAM层级封装。恢复后的源码与先前通过验证的快照逐字节、SHA256一致；复用原129项PW8和216项K3主用例的通过证据，没有重新运行仿真或综合。

保留1×1的输入预取、1KiB权重复用和输入面板复用；保留3×3字缓冲、横向窗口及权重复用。补边、Add读取合并、Post16/Add32配置均未修改，哈希已核对。没有修改时钟，也没有启动整图。

这次只撤销卷积DSP实验，不全局禁用其他模块原有的DSP使用。此前DSP映射的报告/网表/日志作为历史实验保留，不代表当前生产实现。

恢复原版不等于已满足100MHz：映射前的时序限制仍然存在，未执行新的时序收敛检查。
