## 改动

- 普通3×3与DW3共用的两套空间卷积、六套PW8，均显式开启READ_AHEAD；每套最多四笔有序读取，四槽数据本体16字节。
- READ_AHEAD参数默认0，保留旧串行接口兼容；当前fixed_schedule_compact的八个卷积实例显式设置1。每次新任务清空预取标签，避免工作空间复用后读到旧数据。
- 四bank仍共392KiB（96＋96＋100＋100KiB），每个bank的计算口最多每拍一个32位访问；原DATA MOVER与DDR模型不变。
- bank版采用已审阅bai-datasram提交cbf211753b1687bb104d81af2bbf626302a9a13e的四bank分页器，新增每客户端信用与顺序保护。同一客户端跨bank、慢速首次命中或缺页时先排空先前请求，避免无ID接口乱序。
- 后处理、Add、Pad数量与计算不变，共享bank访问也受益。没有增加二级缓存，没有接回已撤销的卷积→后处理FIFO，也没有启用另一个整字装填/整笔写回原型。
- 这次收益是bank并行仲裁、命中流水与连续读取的合计，不能全部归因于预取。

## 测试范围

当前减配网络每图129任务，关闭DW7及其后处理，输出7×7×128特征图，不能称作原始完整MobileFaceNet的128维人脸特征。使用现有测试图量化张量与诊断量化参考，不评估识别准确率。
真实CPU配置、CNN、392KiB共享RAM和MOVER参与，PS GP0与AXI3 DDR由测试模型提供。两图按32位字交错装填，完整输入都到齐后依次提交两个frame，计算可重叠。不是UART输入，不是同图条带边输入边计算。

240组PW8/K3/DW3单元数值测试及取消/重启等通过；四客户端共9,216笔混合字节/字读写、跨页与替换测试通过，fence后DDR逐字节核对。新旧均通过16任务小门槛与258任务两图大门槛。所有MAC计数逐任务一致。
DW3的权重装载可使用连续读取；稀疏的逐通道图像访问仍按安全单笔访问。未对所有访问盲目预读。metrics中的max_pending是同拍先计新接受再扣应答的保守峰值，不应把它直接解释为寄存器中保留的未完成数量。
100MHz只是周期换算条件，未做资源综合、时序或布局布线验证；不承诺板上频率和LUT成本。电脑仿真耗时与硬件条件时间不同。
