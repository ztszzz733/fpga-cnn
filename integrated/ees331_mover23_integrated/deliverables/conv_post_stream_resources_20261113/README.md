## 统计口径

- Vivado 2025.2，xc7z020clg484-1，MAX_CHANNELS=512，FIFO深度8，后处理GROUP_BYTES=16，单线程out-of-context综合。
- 两种卷积分别实例化同一类“一个卷积＋一个后处理”的独立组合。所有正常配置端口保留为运行时输入；显式调试端口不作为顶层输出，不强行保留无用监视计数器。
- 旧组合使用直连改动前、通过回归的卷积与后处理源码快照，增加最小顺序启动及描述符锁存包装；新组合使用已验证的conv_post_pair_engine原型。比较包含新增准入检查器等控制成本，不是只比较算术核心。
- 两个组合都保留现有卷积/后处理计算单元。新增LUT不能解释为又复制了一套MAC，FIFO本体的LUT也不能当成整条流水的成本。
- 未接入共享算子池、跨算子路由网络或完整SoC。不能把某行差值直接乘卷积数量当作整机增量：共享后处理、检查逻辑和通路会改变实际资源。
- 本次只统计综合资源，没有布局布线、整图仿真或板级时序结论，也没有改生产RTL、MAC数量或DSP映射设置。
