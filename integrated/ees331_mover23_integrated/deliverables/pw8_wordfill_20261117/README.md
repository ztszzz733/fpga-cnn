# PW8寄存器重排装填试验（2026-11-17）

**功能、实际存储对比和单模块资源统计均已完成。装填阶段减少24.94%，两图整层总周期减少2.12%；代价是每套增加679 LUT、782 FF，BRAM/DSP不增加。LUT成本偏高，因此保留为默认关闭的可选参数，不推广到全部六套。**

## 做了什么

- 新增参数`INPUT_WORD_FILL=0`。设置1时，对LINEAR_GROUPS=1、输入首址4字节对齐、Ci为4的倍数的普通1×1任务启用。
- 把装填顺序改为收集8个空间位置的4个通道，使用两个32B寄存器暂存块重排，再按64位整行写回原有4KiB输入RAM。
- 暂存数据本体为64B/512bit；还需要保存8个位置地址和控制状态，实际FF增量以综合为准。
- 非对齐、奇数通道和旧矩形分组保留原装填路径。计算通路、16路MAC、2KiB权重RAM和输出队列保持原结构。
- 外部仍是32位、单在途请求协议。本次没有实现大块DMA直灌算子或4笔在途读取，不需要多个外部bank同时向同一算子送数。

## 实际新存储路径的性能

使用此前`storage_plan_perf_20261117`相同的两张14×14×64合成输入、64输出通道、真实PW8和新显式本地存储；只对实例0开启，实例1保持原样。计时包括LOAD、计算和STORE到DDR结果可见，不包含CPU/UART/后处理，不是整网。

| 指标 | 关闭 | 仅实例0开启 | 变化 |
|---|---:|---:|---:|
| 实例0装填阶段周期 | 12,556 | 9,424 | -24.94% |
| 实例0输入RAM写次数 | 12,544 | 1,600 | -87.24% |
| 实例0 RUN周期 | 88,081 | 85,018 | -3.48% |
| 两图从开始搬入至DDR输出可见 | 144,209 | 141,146 | -2.12% |
| DDR读取字节 | 29,184 | 29,184 | 不变 |
| DDR写回字节 | 100,352 | 100,352 | 不变 |

100MHz条件换算，两图为1.44209→1.41146ms；不代表板级频率已经验证。原始输出100,352B逐元素匹配同一整数参考，有效MAC和每实例51,200个MAC工作拍相同。

装填减少没有同比变成整层加速：读取响应、权重装载和输出写回仍占时间，外部单在途限制也仍在。写次数指内部RAM写事务；尾空间位置允许写入内部不参与计算的字节，所以并非恰好8倍关系。

## 功能与协议验证

213组参数各运行独立旧版、新装填、关闭新功能及矩形分组配置，均通过整数参考、地址范围、写覆盖、保护字节和MAC计数检查。50组总周期改善、163组不变、没有退步；请求数和有效读取字节数全部相同。关闭参数逐周期复现独立原版。

另覆盖背压保持、单在途、立即响应、clear/restart、描述符锁存、非法配置和连续任务。最终源码与所有新测数据的SHA256一致。

## 单PW8资源与时序

Vivado2025.2、xc7z020clg484-1、MAX_CHANNELS=512、kernel固定1、10ns、单线程、OOC综合、相同端口和flatten设置。旧数复用2026-11-15已核验同源码同流程结果，本次只重新综合开启的新版本。

| 资源 | 原16路PW8 | 开启新装填 | 增量 |
|---|---:|---:|---:|
| LUT | 3,566 | 4,245 | +679（约19%） |
| FF | 2,101 | 2,883 | +782 |
| BRAM36等效 | 2 | 2 | 0 |
| DSP | 0 | 0 | 0 |
| LUTRAM，已计入LUT | 44 | 52 | +8 |

最终输入RAM仍为1个RAMB36；权重共2个RAMB18。初稿两种写法混用曾导致输入RAM被推成LUTRAM，未采用；已整理成一个写地址、数据总线和字节使能，最终报告不存在该降级。

综合WNS=+0.297ns、WHS=+0.189ns，10ns内部检查通过；未布局布线、未综合整机，不能保证上板100MHz。默认关闭版本的整机资源没有重测；六套增量也不能直接当作整机精确结果。

## 代码状态和使用

生产文件`rtl/cnn_self/self_pw8_engine.sv`增加可选参数，默认0。实例化时显式设置`.INPUT_WORD_FILL(1)`才能开启；当前调度器没有给任何一套设置1。本交付提供完整候选源码和相对旧版补丁，原版备份为`original_engine.sv`。

原有算子、CPU、存储接口和六套实例配置未改。八bank划分和大块装填入口仍是后续工作，不属于本次实现。
