## 实测收益

全部数字来自同一单元顶层中的冻结旧实现与新实现，使用相同数据、确定性反压模型及独立整数参考。周期包含单元装载/计算/写回，不能外推为DDR或完整网络增速。

- PW8：87主用例，86变快、1不变、0变慢。Ci64/Co64场景读取字节和请求数不变，收益来自外部读取与本地RAM填充重叠。Ci128/Co8整层1024字节权重可复用，读取字节10624→5504；Co9超过容量，继续使用原权重双缓冲，仍有输入预取收益。
- Post/Add：40主用例，32变快、8不变、0变慢。Post仍需读取每个INT32，分组16→32只减少流水排空；Add用A/B两个字缓冲合并相邻字节读取，降低请求数，不减少每个输入元素本来必需的数据字节。
- Pad：46主用例，30变快、16变慢。112RGB读请求37632→9408，读字节仍37632；总请求76620→19998。主要收益来自把原先逐字节搬运改为连续字读写。原本已经按32位访问的4倍数通道没有流量收益，新增设置及行分段开销导致小幅变慢；这类情况宜保留旧路径，不能把新版Pad宣传为全配置更快。更小尺寸也可能因设置开销受影响。

## 成本（源码容量，不是综合LUT/FF）

| 算子 | 新增/复用的存储与控制 |
|---|---|
| 每套PW8 | 原有双权重银行共1024字节不扩容，用作放得下的整层权重缓存；新增一个32位输入预取字，及数量/通道/像素索引、有效位等元数据，另有权重偏移和命中控制。 |
| 每套Post | 输出分组16→32，输出暂存多16字节（128个数据位）；分组计数和流水线标签随之加宽。参数BRAM保持原声明。 |
| Add | 同样多16字节输出暂存；另有A/B各32位读缓冲，共8字节，加两个地址标记、有效位、在途事务控制和范围比较。 |
| Pad | 新增字拼装和最近读取字缓存等小寄存器；地址以递增方式推进，尺寸通过串行乘法准备，替代原先持续计算坐标乘法。精确LUT/FF/DSP变化尚未综合。 |

没有新增BRAM数组声明，但映射后的BRAM/LUT/FF/DSP增量仍需综合确认，不能据几字节数据容量推算为零LUT成本。按照当前6套PW8、2套Post、1套Add，PW8预取数据与Post/Add输出暂存及Add读缓存合计新增80字节数据位，尚不含地址标记、控制、Pad寄存器及综合优化变化。

## 正确性、限制和关闭方式

PW8核对所有数值、MAC数量、输入/权重读取计数、反压、立即返回、容量边界、clear重启及无复位同地址换数据。Post/Add使用128位独立整数参考，覆盖极值、正负舍入、钳位、头尾、非法参数、重启、锁存、无复位复用，另增加12组输入输出地址重叠的旧新/独立参考检查。重叠地址时禁用Add预读，并将32元素组退回原16元素边界。Pad独立逐事务参考覆盖46主用例、10组输入输出重叠、4组立即应答、7类非法描述符、clear及无复位复用。

- PW8：INPUT_PREFETCH=0、WEIGHT_LAYER_REUSE=0可关闭新功能。
- Post/Add：GROUP_BYTES=16、READ_WORD_BUFFER=0可关闭新功能；生产调度器当前参数已改为GROUP_BYTES=32。
- Pad：ROW_PACKING=0选择文件内保留的原实现。当前候选新版仍默认开启，尚未针对已对齐通道自动选旧路径；本报告不把它当作所有配置都值得替换的最终定版。
