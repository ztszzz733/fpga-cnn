## 六套PW8的估计影响

按当前6套简单相乘，本次改动估计增加 **5,532 LUT、2,376 FF、3 BRAM36等效块、0 DSP**。

这只是单模块增量×6，不是重新综合整个CNN/SoC后的结果。整机中未使用的统计端口、常量、共享控制和层级优化可能被裁剪或合并，因此不能把该估计直接加到任何历史整机LUT数，作为当前整机精确占用。

输入RAM仍为4KiB，权重逻辑RAM由1KiB增至2KiB；BRAM物理资源按块粒度分配，因此应以上表实际利用率为准。BRAM36等效0.5表示一个RAMB18的容量口径，不是半个可任意拆分的物理RAMB36实例。原8项写队列保持不变。

RTL每套增加8路乘法/累加通路；这与DSP数量不是同一概念，DSP列是本次Vivado实际映射结果。未额外施加新的DSP映射指令或改变原流程。
