# 1×1：在现有输入RAM中扩大数据复用范围

本轮只改PW8内部，未启动整图或SoC集成仿真，未做整机综合、布局布线。保留现有其他算子的候选改动，未修改CPU、共享RAM或算子间存储交换方式。

## 做法

原输入RAM为512×64位，即4KiB。处理Ci64时，一个4×2小块仅占64行，过去余下空间没有用于跨块复用。本次将多个4×2小块暂存到该RAM的不同通道行中，循环顺序改为：加载一个输入面板→读一个输出通道权重→用它依次计算面板内各小块→切换下一个输出通道→处理下一个面板。

仍然只有8路MAC。下表8×8等是输出空间的缓存覆盖范围，不是PE阵列尺寸。输入采样地址按stride1/2分别计算，每个被选中的输入像素只加载一次；8项输出FIFO仍保存绝对地址，计算顺序改变但HWC输出布局不变，done仍等最后写应答。

| 条件 | 最大面板覆盖范围 |
|---|---|
| Ci≤64 | 8×8（8个4×2小块） |
| 64<Ci≤128 | 8×4（4个小块） |
| 128<Ci≤256 | 8×2（2个小块） |
| Ci>256 | 保留4×2 |

仅整层权重大于原1KiB权重缓存时启用；原来放得下的权重继续使用已有整层权重复用，不改变其路径。边界自动缩小面板。PANEL_REUSE=0关闭本轮功能；CPU接口不增加寄存器或命令。

## 实测（相对上一轮已有输入预取和1KiB权重复用的版本）

| 单元配置 | 外部读字节 | 执行周期 | 耗时减少 |
|---|---:|---:|---:|
| 7×7, Ci64/Co64 | 35904 → 7232 | 52471 → 41074 | 21.72% |
| 7×7, Ci128/Co128 | 137344 → 39040 | 172732 → 147785 | 14.44% |
| 7×5, Ci128/Co8 | 5504 → 5504 | 13375 → 13375 | 0.00% |
| 7×5, Ci128/Co9 | 11392 → 6784 | 14959 → 13291 | 11.15% |
| 28×28, Ci64/Co64 | 451584 → 115712 | 702627 → 528085 | 24.84% |
| 28×28, Ci128/Co128 | 1705984 → 559104 | 2239832 → 1861895 | 16.87% |

7×7 Ci64/Co64中，输入仍读取3136字节，权重从32768降到4096字节，总读取减少79.86%。原因是整个7×7输入可以放入同一面板，权重无需随8个小块重复读取。输出写入和MAC数量没有减少，因此耗时并不同比下降79.86%。

28×28 Ci64/Co64中，权重装载从98个小块对应的98轮降为16个面板对应的16轮。输入不重复读，总读取451584→115712字节，耗时减少24.84%。原本已能完整缓存权重的Ci128/Co8维持不变。

129个主数值用例：39变快、90不变、0变慢。覆盖通道阈值两侧、步长1/2、对齐/不对齐、尾块、容量边界、28×28较大数据、13类非法配置、反压稳定、立即应答、clear重启、无复位同地址换数据、独立标量参考、输出守卫/写覆盖及MAC/输入/权重装载计数。每例另运行PANEL_REUSE=0，周期/请求数/读字节与冻结上一版逐一相同。

## 资源与时序

| 单模块独立综合 | 上一版 | 本轮最终版 | 单套增量 | 6套估算增量 |
|---|---:|---:|---:|---:|
| LUT | 2671 | 3073 | +402 | +2412 |
| FF | 1656 | 1722 | +66 | +396 |
| BRAM36等效 | 1.5 | 1.5 | +0 | +0 |
| DSP | 0 | 0 | +0 | +0 |
| LUT RAM | 44 | 44 | +0 | +0 |

输入RAM、权重RAM和8路MAC数不增加，成本来自面板索引、地址生成和控制。六套是单模块差值乘六，不是整机实测；不据此承诺当前整个SoC能放下。

采用Vivado 2025.2、XC7Z020-CLG484-1、10ns独立综合，kernel固定1，保留其他端口。两版综合WNS：旧-2.316ns、新-1.087ns；这不是整机布局布线结果。最终独立综合未满足10ns约束，100MHz仅可用于条件换算，不能声称上板能达到100MHz。

初版面板逻辑曾得到WNS -3.468ns，检查后将权重模式判断和末拍比较移至描述符配置阶段。最终回归与初版面板的每例周期、请求数、读字节完全一致，没有为时序优化增加运行周期。

代价还包括面板计算前装入更多像素，首个输出延迟可能增加；本次测量整条卷积命令完成时间，未单独评估首输出或多图吞吐。Ci>256以及小权重层不会获得本轮跨块复用收益。

最终单元编译25.246s、执行9.878s。最终新单核综合95.047s，旧版报告复用；此前两版初测另计。完整网络加速尚未验证。
