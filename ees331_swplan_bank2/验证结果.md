# 两 bank 与软件规划访存的功能验证

本轮只修改代码并运行功能仿真，没有启动新 Vivado 综合、布局布线或上板操作。100 MHz 仍是目标时钟，不是本轮已通过的时序结果。

## 配置与源码

共享缓存为两个 196 KiB bank，总容量 392 KiB；保持 392 个 1 KiB 页。执行单元为两个 K3、四个 PW8、两个 Post、Add、Pad。板级顶层源码与基线逐字节相同，SHA-256 为 `d14b5041a9c708e814b6d2720ac0b8278f275cec932e9451a9d5f78f3772f35c`。

K3 任务由软件提供读跨度、张量范围、读宽和复用模式。专用有界读段适配器替换 K3 的旧自动扩宽和地址匹配式预取控制，数据/响应寄存后再推进算子状态。共享缓存的两路仲裁、页槽到 bank 的映射以及返回路径一起适配，未仅关闭两路端口。

## 已通过的测试

| 测试 | 结果 |
|---|---|
| 两 bank 缓存专项 | PASS，2,491,492 周期，250 次计算/DMA 页隔离检查 |
| 软件读段适配器 | PASS，31,205 周期 |
| K3 独立标量参考 | PASS，40 组普通/depthwise 卷积，34,181 周期 |
| 完整双图 | PASS，两张不同 112×112×3 输入，258 个任务 |
| 中间输出校验 | 38,730,904 字节匹配 |
| 最终输出 SHA-256 | `97ea50f0e05b15b7d5ed6bee04916069461be37259418bf112155aab80035018` |

缓存专项验证两个物理 bank 实际同时发出计算请求，并让四个客户端争用两 bank；不同地址使用不同数据模式，检查返回顺序与内容。还覆盖 401 页脏淘汰、替换回绕、字节写、部分页刷新、失效重装、取消排空、AXI 错误恢复和只读保护。

读段专项覆盖 byte/word 模式、段长与溢出检查、FIFO 满载与随机等待、稳定请求、有序回复、读写转换、零周期写完成、取消屏障和非法响应。K3 参考测试覆盖 stride 1/2、通道 1/3/4/5/8、非对齐地址、部分 tile、halo 复用、整层权重复用和非法计划拒绝。

## 双图运行记录

总周期 180,785,683。按目标 100 MHz 换算为约 1.808 秒；该数值来自功能模型，不能作为板上速度。原四 bank、未采用软件读段的功能基线为 180,185,206 周期，本次增加 600,477 周期，约 0.33%。本轮同时改变 bank 数和 K3 访存控制，不能据此单独归因于其中一项，也不能推广到所有模型。

HP0 模型累计读取 71,562,240 字节、写入 37,423,104 字节。保留原有双图、模型、DDR 分区、参考数据及 129 个任务模板，仅转换其中 17 个 K3 模板的读计划字段。

PLAN.BIN SHA-256：`90af2634084dbb237494c927133b9c4bba956f70f1414dd4ceb244a6968a1bde`。

测试实际运行 RISC-V ROM/CPU、CNN、缓存和 Mover RTL，ARM 公共调度 C 逻辑在原生环境执行，PS/DDR 使用带等待的模型。它不包含 ARM 内核和 FreeRTOS 内核的板上执行验证。本轮提供适配后的 FreeRTOS 软件源码与计划文件，没有生成新的 ARM ELF、bitstream 或 BOOT.BIN。
